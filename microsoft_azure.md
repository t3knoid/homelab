# ☁️ Microsoft Azure
 
**Microsoft Azure is a cloud computing platform that provides on‑demand infrastructure, identity services, and application hosting.** It offers scalable compute, storage, networking, and security capabilities that integrate tightly with [Microsoft Entra ID](microsoft_entra_id.md) for authentication and access control.

**In this homelab, Azure’s identity platform—Microsoft Entra ID—is used to securely authenticate users and applications, providing the OAuth2 foundation that protects internal services behind the reverse proxy.**
