# 📝 Redmine

Redmine is the central hub for project and task management within the homelab. It provides full visibility into ongoing work, tracks improvements, and serves as an integrated documentation platform.

## Key Functions

* **Project & Task Tracking** – Organize and monitor tasks across all infrastructure components.  
* **Issue Management** – Log and track lab improvements, troubleshooting efforts, and feature requests.  
* **Integrated Documentation** – This wiki contains architecture diagrams, system configurations, runbooks, and operational procedures.  
* **Code Integration** – A local Git repository mirror enables viewing Ansible code changes and history directly within Redmine.
